# Support

This repository is part of the FoggyKitchen training ecosystem and is provided as an educational Terraform/OpenTofu module.

## Scope

Issues and improvements should focus on:

- Terraform/OpenTofu module correctness
- Azure Cosmos DB resource composition
- Example clarity
- Documentation fixes
- Compatibility with supported provider versions

This module does not provide production operations support, Azure account support, or application database design support.

## Security

Do not open public issues containing secrets, connection strings, access keys, Terraform state, or private subscription details.

Rotate any credentials that were committed, pasted into logs, or shared accidentally.
